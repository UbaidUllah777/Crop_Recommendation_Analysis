# Crop Recommendation Analysis

## Project Overview
This project analyzes how soil nutrients and environmental conditions influence the selection of suitable crops. It focuses on key agricultural variables such as nitrogen, phosphorus, potassium, temperature, humidity, pH, and rainfall to identify crop patterns and support data-driven recommendations for precision farming.

The analysis aims to answer the research question:

> Which soil composition and environmental factors are most strongly associated with specific recommended crop types?

By exploring these relationships, the project provides insights into the agronomic requirements of different crops and helps improve decision-making in agricultural planning and crop management.

---

## Objective
The main objectives of this project are to:
- Evaluate the relationship between crop type and soil nutrient levels.
- Examine how climate variables affect crop suitability.
- Identify patterns in crop requirements using statistical analysis and visualizations.
- Present findings in an interpretable and professional format.

---

## Dataset
The project uses the Crop Recommendation Dataset from Kaggle.

Source: https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset

### Features in the dataset
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- pH
- Rainfall
- Crop Label

---

## Methodology
The workflow includes:
1. Data loading and cleaning
2. Renaming and standardizing columns
3. Handling duplicates and preparing the dataset
4. Statistical profiling using key measures such as mean, median, mode, variance, standard deviation, and quartiles
5. Visual analytics including:
   - Box plots
   - Histograms
   - Scatter plots
   - Venn diagrams
6. Interpretation of insights based on the analysis

## Key Findings
The analysis highlights several important agricultural insights, including:
- Nitrogen requirements vary significantly across crop categories.
- Rainfall distribution shows a concentration of crops in moderate rainfall conditions.
- Temperature and humidity reveal distinct crop-specific clusters.
- Environmental overlaps help identify conditions where multiple factors jointly influence crop suitability.
